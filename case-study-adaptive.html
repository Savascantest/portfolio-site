01 / Problem

Group learning can reproduce inequality.

When a single curriculum, task or assessment is applied to learners with different prior knowledge, competencies, motivations and support needs, “working together” does not automatically mean learning together.

The project began with the challenge of low effectiveness in group learning and evolved across internship reports, interdisciplinary work, personas, journey maps, solution explanations, interface mockups and pitches.

02 / System concept

A loop, not a one-time label.

Input

Understand the starting point

Gather diagnostic evidence about prior knowledge, competency, preferences, accessibility and motivation.

Design

Compose and scaffold

Use the learning purpose to shape groups, differentiated tasks and roles.

Activity

Make learning observable

Structure project work so contribution, collaboration and development can be discussed.

Feedback

Update the picture

Use teacher rubrics and progressive assessment to inform the next cycle.

04 / Critical learning

From fixed “learning styles” to learner variability.

Some early versions used learning-style language too confidently. Later work recognized the evidence problem. The stronger formulation focuses on prior knowledge, competencies, preferences, accessibility, motivation and adaptive scaffolding—dimensions that can be observed, discussed and revised.

Adaptation should support learners without freezing them into categories.

05 / Status & boundaries

A developed concept, not a validated product.

The project includes substantial research, service-design and interface artifacts, but it was not deployed as a production platform and no learning-effectiveness outcome is claimed. Any future implementation would need educator co-design, data-governance review, accessibility testing and empirical evaluation.

Public-safety choice: this case uses original abstract diagrams. It does not publish third-party stock images, learner/persona photos, institutional marks, private contact details or unredacted source documents.
