# Savaşcan Türken — portfolio website

This is a privacy-safe rebuild of the existing `Savascantest/portfolio` site. It is a dependency-free static site designed for GitHub Pages or any standard static host.

## Positioning

The site presents Savaşcan as a learning architect and educational-technology professional connecting language education, instructional design, qualitative research and responsible technology.

The information architecture deliberately separates:

- completed research;
- professional work and practice;
- functional or playable prototypes;
- research-informed concepts;
- exploratory learning artifacts.

## Selected public work

1. Online language-learning transition — completed M.A. research.
2. Adaptive group learning and evaluation — research-informed product concept.
3. Path to Enlightenment — playable Unity/C# serious-game prototype.
4. Language learning activity studio — functional browser prototypes and professional teaching practice.
5. Ultra Smart School — bounded professional summary without proprietary evidence.
6. Language quality and AI evaluation — bounded professional summary without client-confidential evidence.

Exploratory concepts are grouped separately and carry explicit scope limitations.

## Privacy and publication safeguards

- No phone number, street address, permit number, credential identifier, signature or unredacted credential is included.
- No learner names, learner records, raw interview responses or private tutoring content is included.
- No proprietary platform screens or client-confidential task content is included.
- Direct email is omitted; public LinkedIn and GitHub profiles are used as contact routes.
- Tokenized research links from the previous homepage are removed.
- The previous public files containing learner essays, individualized interview preparation and personal CV-builder data are excluded from this rebuilt public package.
- Original CSS/SVG diagrams replace third-party stock images and institution-branded screenshots.

## Files

- `index.html` — portfolio homepage.
- `case-study-research.html` — completed thesis research case.

- `unit_10_opportunities.html` — retained public-safe interactive prototype (not linked from the homepage).

## Local preview

Serve this directory with any static file server and open `index.html`. The homepage and case studies use no build step or package dependencies.
